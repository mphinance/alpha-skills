# 📈 Quant Skills Plugin

**63 Elite Quantitative Trading, Market Intelligence, and Execution Skills for AI Agents**

This plugin equips Claude Code, Antigravity, and Gemini with an institutional-grade quantitative trading brain.

## Key Capabilities

- **Broker Execution**: `webull-openapi` (official Webull SDK CLI integration), `broker-mcp-selector`, `ghost-auto-trader`
- **Stock Screening**: `canslim-screener`, `vcp-screener`, `pead-screener`, `dividend-growth-pullback-screener`, `batch-scanner`, `finviz-screener`
- **Technical Analysis & Pine Script**: `technical-analyst`, `breadth-chart-analyst`, `uptrend-analyzer`, `mph-pine`, `pine-to-python`
- **Macro & Market Regimes**: `macro-regime-detector`, `market-environment-analysis`, `market-top-detector`, `ftd-detector`, `us-market-bubble-detector`
- **Options & Risk Management**: `options-strategy-advisor`, `position-sizer`, `exposure-coach`, `0dte-flow`, `magnet-path`, `momentum-squeeze`
- **Edge Discovery & Backtesting**: `backtest-expert`, `edge-pipeline-orchestrator`, `quant-feature-engineer`, `scenario-analyzer`, `stanley-druckenmiller-investment`
- **News, Earnings & Dividends**: `market-news-analyst`, `earnings-calendar`, `earnings-trade-analyzer`, `kanchi-dividend-sop`, `stock-recap`, `stock-analyzer`

## Installation

In Claude Code:
```bash
/plugin install quant-skills@mphinance
```
